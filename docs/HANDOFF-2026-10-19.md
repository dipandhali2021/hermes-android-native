## What is implemented

The integrated build is the union of milestones M0–M8 and nine feedback rounds.

**Platform and shell**
- M0 skeleton, theme, CI producing an APK.
- M1 navigation, design tokens, expressive motion.
- M2 settings persistence.
- M3 networking core and Connect screen.
- Material 3 Expressive theme, Material You dynamic colour on Android 12+,
  generated Hermes-gold fallback below that, live light/dark/system switching.

**Connect and auth**
- URL + optional password; connection test distinguishes unreachable host,
  wrong address, TLS problem and bad password. Cookie jar is cleared on URL
  change.
- Credentials stored through the settings store; password never logged.

**Sessions**
- List, search, create, rename, archive, delete; live indicator for a session
  currently answering.
- Home screen create-and-send flow with a state-driven spinner and error
  snackbar; offline icon monograms and relaunch recovery.

**Chat**
- Streaming tokens, reasoning disclosure, tool calls with results/failures,
  warnings and context-compression notices.
- Markdown with code blocks and syntax colour; assistant prose unboxed,
  user messages in bubbles.
- Composer state machine: send, stop, steer, `/queue`. Home and chat composers
  share the same component.
- Model picker: search, provider groups, selected state, show-more, provider
  icons, model + provider sent with the turn.
- Context-window meter: digit-free ring, bottom-sheet usage card, honest
  fallback when the server reports no window; nothing invented.
- Reconnect/gap recovery after backgrounding is **not** implemented (see gaps).

**Composer extras**
- Attach panel: Photos / Camera / Files tiles, separate card below the composer,
  keyboard-height swap, `+` ↔ `×` toggle.
- Attachments: 10 files / 20 MB, session-scoped upload, retry without
  re-upload, optimistic tray, photos and camera capture.
- Voice: transcribe (server STT, auto-sends) and voice note (audio attachment,
  auto-sends); mode persists per app run; 503 surfaced verbatim.
- Saved prompts: save draft, library sheet, compose-with, swipe/× delete with
  inline undo, long-press send to save.
- Agent profiles: picker, switch (replace non-empty chat / re-tag empty chat),
  manage, create with the web's fields and server-verbatim errors.
- Workspaces: picker, in-chat switch rules, home retargeting, worktree new
  conversation, typed path with trusted-roots typeahead, manage sheet.
- Workspace files: view-first browser, breadcrumbs, one-level expansion,
  text/image/PDF preview, create/rename/delete/upload, escape-safe symlinks.
- Chat media (Round 9): image thumbnails in user bubbles, inline audio player
  with seek and 1×/1.5×/2× speed, file rows that open preview; attachments
  parsed from server data first, then from the send-side marker for old
  sessions; file preview can play audio.
- Sheets: Material 3 partial detent + expand; sub-sheets stack over their
  picker; path entry is a sheet.

## Known gaps and deliberate omissions

- **Reconnect/gap recovery after backgrounding** is not implemented. The wire
  contract is documented in [`sse-integration.md`](sse-integration.md):
  `/api/chat/stream` is not a replay source; use the run-journal relay with
  opaque `Last-Event-ID`. This is the main remaining robustness gap.
- **No offline cache** by design: the agent runs on the server; a read-only
  cached transcript was judged worse than an honest offline state.
- **README roadmap checkboxes are stale.** The model picker, attachments and
  voice are implemented even though the list still shows unchecked items. Use
  this handoff and `HANDOFF-model-picker.md` for feature state.
- **`master` is far behind.** It predates everything from the model picker
  onward. Integration strategy is a user decision, not an agent default.
- **Voice-note transcription is server-side.** If the WebUI tries to download
  a local Whisper model instead of using the configured provider, check that
  the WebUI service's `HERMES_HOME` points at the shared config. The deployment
  investigation is in the local SDD ledger, not in tracked docs.
